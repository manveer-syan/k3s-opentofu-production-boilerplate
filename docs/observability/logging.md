# Centralized Logging Architecture & Data Sanitization Standard

> **Document Version**: 1.0.0  
> **Target Subsystem**: Observability — Centralized Logging  
> **Collector**: Fluent Bit v2.2+ (DaemonSet / ~25MB RAM footprint)  
> **Log Sink**: AWS CloudWatch Logs (`/aws/k3s/manveersyan-group`)  

---

## 1. Architectural Decisions & Memory Efficiency

On an EC2 `t3.small` / `t3.medium` instance running K3s, heavy Java or Elasticsearch based log collectors (Logstash, Filebeat with OpenSearch) consume upwards of 1.5GB to 3GB of RAM and will crash the node.

### The Lightweight CloudWatch Ingestion Pattern
1. Containers write strictly structured JSON logs to `stdout` / `stderr`.
2. K3s Containerd writes these streams to `/var/log/containers/*.log`.
3. **Fluent Bit** runs as a lightweight log forwarder (`aws-for-fluent-bit:latest`), consuming only **~25 MB of RAM** and < 2% vCPU.
4. Fluent Bit uses the EC2 host's IAM instance profile (`AmazonSSMManagedInstanceCore` / CloudWatch Logs permissions) to ship log streams directly into **AWS CloudWatch Logs** (`us-east-1`).
5. Grafana queries CloudWatch Logs directly via the AWS CloudWatch Datasource plugin without requiring an in-cluster storage backend.

## 2. Structured Log Schema Standard

Every Go and Node microservice must output logs adhering to this JSON schema:

```json
{
```

## 3. Strict Data Sanitization & PII Masking Standards

Developers and operators must enforce that sensitive fields are **NEVER** logged in plaintext:

### Strictly Prohibited Log Fields
* `Authorization` header contents (Bearer tokens, Basic auth credentials)
* JWT raw signature strings or claims containing sensitive identities
* Plaintext database credentials (`DATABASE_PASSWORD`, connection URLs)
* Cryptographic private keys (`AGE-SECRET-KEY-*`, SSH keys)
* One-Time Passwords (OTPs) and verification codes generated by `notification-service`
* Session cookies and refresh tokens

### Application-Level Sanitization Example (Go Middleware)
```go
// SanitizeHeaders strips sensitive auth data before logging HTTP context
func SanitizeHeaders(h http.Header) map[string]string {
    safe := make(map[string]string)
    for k, v := range h {
        lower := strings.ToLower(k)
        if lower == "authorization" || lower == "cookie" || lower == "x-api-key" {
            safe[k] = "[REDACTED]"
        } else {
            safe[k] = strings.Join(v, ",")
        }
    }
    return safe
}
```

## 4. Log Retention & FinOps Governance

* **Application Container Logs**: **30 Days Retention** in CloudWatch Logs (`/aws/k3s/manveersyan-group`).
* **Security & Audit Logs**: **90 Days Retention** (CloudTrail, SSH auth.log, K3s audit logs).
* **Cost Estimate**: At typical microservice volume (< 500MB compressed daily log volume), AWS CloudWatch Logs ingestion and storage costs **<$1.50 per month**, preserving the project's strict FinOps boundaries.
